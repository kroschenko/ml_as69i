# Repository for reports and programs for the "Fundamentals of Machine Learning" course

1. Fork the repository
1. Complete the assignment
1. Submit a pull request to the `master` branch

Commands:
1. **git clone** <your_repo_url> — to clone the repository to a local folder
1. **git add** * — to add all files to the list of tracked files
1. **git commit** -m "message" — to create a commit (after adding files); replace "message" with your actual message in quotes
1. **git push** — to push changes to your remote repository

After performing these steps, go to your repository on the website, select **Contribute**, and click the **Open pull request** button (the green button). If everything is correct, a page will open that also features a green **Open pull request** button; click it.

Commit reports to: **reports/<Your_Surname>/<Lab_Number>/rep**

Commit code to: **reports/<Your_Surname>/<Lab_Number>/src**
